Principles

What changes compared to Painter, and why artists will feel it.

The model is the canvas

The 3D view fills the whole window. Panels float above it with an 8 to 10 px gap, so the model is never boxed in by docks. Tab hides everything.

One dock for every tool

All tools sit in a single dock at the bottom, grouped: select, paint, fill, path, utilities. The options of the active tool appear right above it, where the eye already is.

Layers where Figma has them

Project, texture set and layers on the left, in one column you read top to bottom. Library top right, properties bottom right: drag from the library, tune below it.

Rounded, soft, quiet

12 px panels, 8 px controls, pill sliders and chips. Few borders, depth from soft shadows. Color only where it means something: orange is action and selection, red is mask.

One place per action

Every command has one home and one shortcut. No duplicated menus, no disabled placeholders. Advanced options fold away instead of crowding the panel.

Photoshop muscle memory

B, E, M, L, W, G, Q, I, S, R: the keys painters already know. Hover any tool to see its key.

Color

Neutral graphite surfaces that rise in lightness, the forge orange of the logo as the only brand color, and a few meaning colors.

The tool dock

Five groups. A group shows its last used tool; a small corner mark means a flyout with the others. Each tool's options appear in the floating bar above the dock and in the properties panel.
